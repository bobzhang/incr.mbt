How to read this demonstration

These are computation counts, not a timing benchmark. The independent evaluator calculates the same selected view from scratch with ordinary values, sharing each service-area plan once. Every quote and visible plan must match exactly. The UI does not implement incremental caching: the compiled MoonBit engine does. The city and manifest are fictional; the planning rules model service areas and fallback depots, not a global vehicle-routing optimizer.
